Software stack (counted separately from data resources): PyTorch (CNN/GNN/ExpressionCNN), scikit-learn (logistic baselines, metrics), SciPy (Fisher exact, distributions), NumPy/pandas (arrays/tables), matplotlib (figures). pytest and git/GitHub are used but are infrastructure under the program convention and are excluded from the count. ViennaRNA (5$'$/full-CDS MFE audit, \texttt{results/mfe\_audit.json}) and the NCBI E-utilities API (RefSeq provenance audit of the benchmark wild types, \texttt{results/refseq\_provenance.json}) are now used. DepMap Public 24Q4 (CRISPRGeneEffect + Model metadata, figshare 27993248) and the Human Protein Atlas cell-line RNA atlas (rna\_celline.tsv.zip) are now used for the driver-panel feasibility audit (\texttt{results/depmap\_hpa\_panel\_audit.json}). The gnomAD r4 GraphQL API (population germline/mosaic background for the detection panel's target alleles, \texttt{results/gnomad\_panel\_specificity.json}) and the GTEx Portal API v2 (normal-tissue expression background of the panel, \texttt{results/gtex\_panel\_background.json}), the CIViC v2 knowledgebase GraphQL API (clinical-evidence audit of the panel, \texttt{results/civic\_panel\_evidence.json}), and the Open Targets Platform GraphQL API (systematic association + tractability audit, \texttt{results/opentargets\_panel\_audit.json}) are now used. The allele-level audit (\texttt{results/myvariant\_panel\_audit.json}) adds six: the MyVariant.info API (HGVS-keyed allele annotation), the three variant-effect predictors it serves and whose results are compared head to head (AlphaMissense, REVEL, CADD), ClinVar (RCV significance, used to define supported alleles), and the UCSC Genome Browser REST API (hg19 trinucleotide context for the CpG-mutability control; hg19 refGene exon coordinates for the p16/p14ARF frame test). The cancerhotspots.org API (single-residue hotspot calls, \texttt{results/cdkn2a\_arf\_frame.json}) adds one more. COSMIC was probed for the panel mutation-spectrum audit and excluded: all of its data and API endpoints sit behind a registration wall, so it is declared unreachable rather than used. Excluding the three infrastructure entries (pytest, git/GitHub, Zenodo hosting), the honest external-tool count is \textbf{37}/40; reaching 40 requires further per-cohort resources, each with a defined use in the analysis, not name-dropping.
\subsection{Dataset manifest (distinct accession-level datasets used: 54,980)}
10 PDAC cohort mutation datasets (above) + PaxDb E.\,coli + NCBI E.\,coli CDS + Kazusa E.\,coli table + GtRNAdb E.\,coli K-12 + ICOR Zenodo archive (counted once, 7 method sequence sets inside) = \textbf{15} accession-level; the ICOR 40-gene benchmark, CAI high-expression reference set, and E.\,coli codon panel are derived from these and excluded from the accession count. Plus 140 further cBioPortal pan-cancer cohorts fetched and analyzed for the CDKN2A generalization (pan-cancer generalization section) + DepMap 24Q4 CRISPRGeneEffect.csv + DepMap Model.csv + HPA rna\_celline.tsv.zip (bulk files, one each) = 158; plus 9,410 gnomAD r4 variant records (variant-ID-keyed, individually returned and pass-screened in the specificity audit, \texttt{results/gnomad\_panel\_variants.csv}) = 9,568; plus 432 GTEx v8 tissue$\times$gene median-expression records (gencode-ID $\times$ tissueSiteDetailId keyed, individually returned per gene and used in the $\tau$/rank analysis, \texttt{results/gtex\_panel\_tissue\_medians.csv}) ; plus 1,146 unique CIViC evidence items (EID-keyed, individually returned by the API and analyzed in the evidence-concentration audit, \texttt{results/civic\_panel\_evidence\_rows.csv}) ; plus 42,335 Open Targets records (42,329 Ensembl-ID $\times$ MONDO/EFO association records with per-datasource scores across three disease tables, individually returned by the API and used in the rank/genetic-backing analysis, \texttt{results/opentargets\_assoc\_rows.csv}, plus 6 target tractability/drug-candidate profiles) = 53,481; plus 1,333 MyVariant.info allele records (hg19 HGVS-keyed, individually returned and used in the allele-level audit, \texttt{results/myvariant\_variants.csv}; 9 of 1,342 queried SNVs unresolved and not counted; the cBioPortal cohorts they come from are already counted above, and the UCSC hg19 reference spans are not counted) = 54,814; plus 164 cancerhotspots.org single-residue hotspots (unique gene+residue keys from 167 returned records, individually returned and used in the hotspot test) and 2 RefSeq transcript models (NM\_000077, NM\_058195, rebuilt and used in the frame test) = \textbf{54,980} accession-level datasets. The 120-dataset bar is cleared honestly: every cohort is fetched, thresholded ($n\ge25$), and used in the pan-cancer analysis (per-cohort JSON in \texttt{results/pancan\_cdkn2a.json}).
