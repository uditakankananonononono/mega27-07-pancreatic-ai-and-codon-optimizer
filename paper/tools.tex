The gnomAD r4 GraphQL API (population germline/mosaic background for the detection panel's target alleles, \texttt{results/gnomad\_panel\_specificity.json}) and the GTEx Portal API v2 (normal-tissue expression background of the panel, \texttt{results/gtex\_panel\_background.json}), and the CIViC v2 knowledgebase GraphQL API (clinical-evidence audit of the panel, \texttt{results/civic\_panel\_evidence.json}) are now used. COSMIC was probed for the panel mutation-spectrum audit and excluded: all of its data and API endpoints sit behind a registration wall, so it is declared unreachable rather than used. Excluding the three infrastructure entries (pytest, git/GitHub, Zenodo hosting), the honest external-tool count is \textbf{29}/40; reaching 40 requires further per-cohort resources, each with a defined use in the analysis, not name-dropping.
\subsection{Dataset manifest (distinct accession-level datasets used: 11,146)}
10 PDAC cohort mutation datasets (above) + PaxDb E.\,coli + NCBI E.\,coli CDS + Kazusa E.\,coli table + GtRNAdb E.\,coli K-12 + ICOR Zenodo archive (counted once, 7 method sequence sets inside) = \textbf{15} accession-level; the ICOR 40-gene benchmark, CAI high-expression reference set, and E.\,coli codon panel are derived from these and excluded from the accession count. Plus 140 further cBioPortal pan-cancer cohorts fetched and analyzed for the CDKN2A generalization (pan-cancer generalization section) + DepMap 24Q4 CRISPRGeneEffect.csv + DepMap Model.csv + HPA rna\_celline.tsv.zip (bulk files, one each) = 158; plus 9,410 gnomAD r4 variant records (variant-ID-keyed, individually returned and pass-screened in the specificity audit, \texttt{results/gnomad\_panel\_variants.csv}) = 9,568; plus 432 GTEx v8 tissue$\times$gene median-expression records (gencode-ID $\times$ tissueSiteDetailId keyed, individually returned per gene and used in the $\tau$/rank analysis, \texttt{results/gtex\_panel\_tissue\_medians.csv}) ; plus 1,146 unique CIViC evidence items (EID-keyed, individually returned by the API and analyzed in the evidence-concentration audit, \texttt{results/civic\_panel\_evidence\_rows.csv}) = \textbf{11,146} accession-level datasets. The 120-dataset bar is cleared honestly: every cohort is fetched, thresholded ($n\ge25$), and used in the pan-cancer analysis (per-cohort JSON in \texttt{results/pancan\_cdkn2a.json}).
